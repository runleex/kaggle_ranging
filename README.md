# kaggle_ranging

# Выбор модели
Сначала были проверены CatBoost, BGE и GTE. Лучший результат среди них дала BGE. Затем была выбрана Jina v3.5, которая обрабатывает сразу весь список фрагментов одного запроса. Такой подход позволяет учитывать контекст похожих кандидатов. На общей проверочной выборке Jina показала более высокий NDCG@10.
Модель	Проверка	NDCG@10
CatBoost	Public	0,776334
BGE, первый вариант	Public	0,934378
BGE, улучшенный вариант	Public	0,936146
GTE	Public	0,913700
BGE	Отложенные 305 запросов	0,940878
Jina	Те же 305 запросов	0,952775


# Подготовка данных и обучение
Из текстов удалены HTML-теги, служебные строки, лишние пробелы и знаки ударения. Использовались запрос, заголовок и текст фрагмента. Длинные тексты сокращались с сохранением начала и конца. Общий размер входа ограничен 4 096 токенами.

За основу взяты предобученные веса jinaai/jina-reranker-v3.5. Трансформер заморожен, дообучается проектор — два линейных слоя с ReLU, преобразующие представления для расчёта релевантности. Это позволило использовать кэш и сократить расход GPU.

Финальное дообучение проведено на всех 3 042 запросах и 31 530 парах за две эпохи, всего 762 обновления. Использован AdamW с learning rate 1e-5. Функция потерь объединяет попарное сравнение кандидатов и бинарную кросс-энтропию в пропорции 85% и 15%. Для пар из одной статьи вес попарного штрафа повышен до 1,5. Внешние датасеты при дообучении не использовались.
# Результат
Обучение и инференс выполнялись в Google Colab, Linux, на Tesla T4.
